# Thematic-analysis codebook (Track B)

Recoded for the final 12-response panel (responses 29 Aug – 10 Sep 2026); the earlier version of this file was coded on the first ten responses. This file is the source for the dissertation's Приложение Г, which is to be regenerated from it.

Кодирането на отворените отговори (елементи C1–C4 и D1) следва шестстъпковия подход на Braun и Clarke. Всяка тема се документира по единен шаблон, за да остане проследима до изходния материал и да подлежи на одит от съавтор.

Брой респонденти, изразили темата (не брой споменавания — предотвратява надценяване от един словоохотлив участник)

### 

| Поле | Описание |
|---|---|
| Идентификатор | Т1–Тn, присвоен при финализиране на темата |
| Наименование | Кратко описателно име, формулирано като твърдение, а не като категория |
| Дефиниция | Какво се включва в темата и — изрично — какво се изключва |
| Критерий за включване | Условие, при което сегмент от отворен отговор се кодира с тази тема |
| Честота | Брой респонденти, изразили темата (не брой споменавания — предотвратява надценяване от един словоохотлив участник) |
| Засегнати измерения | Кои от Д1–Д8 темата информира |
| Разпределение по групи | Кои от трите групи изразяват темата; разминаването се отбелязва изрично |
| Представителен цитат | Един кратък анонимизиран цитат във вида Експерт-Група-N, проверен за косвено идентифициращи детайли |
| Отношение към количествените данни | Потвърждава / противоречи / уточнява резултата по съответното измерение |
